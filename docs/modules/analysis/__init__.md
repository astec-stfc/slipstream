# `slipstream.analysis`

[Source](../../../src/slipstream/analysis/__init__.py) · [Documentation index](../../README.md)

## Physics

Analysis computes statistics from transported particle data. Emittance meaning follows the selected slope or canonical-momentum convention.

## Usage

Import slice and emittance helpers from their submodules; nonlinear, RF-on ring, LOCO and reporting tools have dedicated modules.
