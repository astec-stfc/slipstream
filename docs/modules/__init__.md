# `slipstream`

[Source](../../src/slipstream/__init__.py) · [Documentation index](../README.md)

## Physics

Public exports collect native transport, machine models, wakes and beam diagnostics. Coordinate conventions belong to each implementation: native ring/linac use canonical momenta, distribution generators use slopes, and injector transport uses Cartesian proper velocity.

## Usage

Import public classes from `slipstream`; consult `__all__` for the supported top-level surface. ASTRA/elegant readers parse local files without launching their executables.
