# `slipstream.wakefields.multilayer`

[Source](../../../../src/slipstream/wakefields/multilayer/__init__.py) · [Documentation index](../../../README.md)

## Physics

Provides round multilayer matching, complex Bessel primitives and geometric Yokoya corrections. The full flat-chamber solver is numerically parked.

## Usage

Import `round_chamber_impedance`/`round_chamber_dipole_impedance` or `yokoya_elliptic_factors` from their modules; no executable solver is required.
