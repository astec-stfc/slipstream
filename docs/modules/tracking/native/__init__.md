# `slipstream.tracking.native`

[Source](../../../../src/slipstream/tracking/native/__init__.py) · [Documentation index](../../../README.md)

## Physics

Exports ring, linac and injector transport and elegant-lattice import. Each tracker implements its documented coordinate regime.

## Usage

Import `NativeTracker`, `LinacTracker`, `Injector`, `Photocathode` (optional laser-driven emission for `Injector`), `ElementSpec`, `parse_elegant_lattice` or low-level `track_element`.
